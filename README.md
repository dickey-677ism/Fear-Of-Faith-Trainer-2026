## 🎮 About the Game

FEAR OF FAITH is a first-person co-op dieselpunk survival horror game developed by UNBREAKABLE ARK and released in Early Access on August 21, 2026. Players control cloned soldiers raiding cursed World War II bunkers to recover SYNTRUM. The game combines action, adventure, stealth, survival horror, physics-based interactions, procedural bunker expeditions, classes, spells, weapons, and online co-op for up to four players.

## 🔥 Project Overview

**This tool** is a comprehensive trainer for **FEAR OF FAITH**. This trainer provides optional control over the game's core survival systems, including health, FAITH, FEAR, ammunition, reloads, resources, and movement. It is designed for solo experimentation, accessibility, testing class and spell combinations, and relaxed exploration of procedurally generated bunkers.

**Target Audience:** Players who want to experiment with classes and spells, practice combat, explore procedural bunkers, reduce survival pressure, test accessibility settings, or replay solo expeditions with less resource management.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## ⚡ Features (v1.0)

### 🎯 Gameplay

- **Infinite Health** — Prevents the player from losing health during bunker expeditions.
- **Unlimited FAITH** — Allows spells and miracles to be used without consuming the player's FAITH.
- **Fear Control** — Locks or reduces FEAR buildup, helping prevent the game's escalating fear effects and transformation stages.
- **Stealth Assistance** — Reduces detection pressure while exploring sound-sensitive enemies, traps, dark areas, and guarded bunker routes.
- **Movement Options** — Provides adjustable movement speed and jump settings for navigation, testing, and accessibility.

### ⚔️ Combat

- **Unlimited Ammunition** — Keeps ammunition available for the game's firearms.
- **No Reload** — Removes reload delays while using compatible ranged weapons.

### 🧰 Inventory

- **Resource Multiplier** — Increases resources collected from bunker exploration, corpses, containers, and mission objectives.

## 📖 Detailed Feature Guide

### Movement & Exploration

Use the movement options to adjust travel speed or jump behavior when navigating bunker corridors, traps, locked routes, and physics-based environmental spaces. Disable movement modifications before interacting with doors, ladders, scripted encounters, or extraction areas if unusual behavior occurs.

### Tools & Inventory

The game uses physical weapons, utility items, consumables, grenades, alcohol, ammunition, and mission resources. Resource multiplier options are most useful after collecting items from corpses, containers, and bunker rooms. Avoid modifying inventory values while throwing, handing over, or catching physics-based items.

### World & Environment

FEAR OF FAITH features procedurally generated bunker expeditions, changing layouts, generators, lights, alarms, traps, loot routes, and environmental interactions. Infinite FAITH and Fear Control make it easier to test spells such as elemental effects, polymorphing, stealth abilities, and other class-specific tools without normal resource pressure.

### Combat & Weapons

Weapons, spells, environmental hazards, and physics-based equipment can all be used against monsters and bosses. Unlimited ammunition and No Reload are intended for weapon testing, while Infinite Health and Fear Control help with boss encounters and learning enemy behavior. Ghouls can be affected by sound, light, fire, decapitation, and other gameplay systems, so trainer options should be combined with the game's normal combat mechanics.
